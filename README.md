# /dev/null for Mac

The native Mac app for [/dev/null](https://dev-null.sh), a social network for devs. It needs macOS 14 or later.

## Install

Download the DMG from [dev-null.sh/apps](https://dev-null.sh/apps), or install it with [Homebrew](https://brew.sh):

```sh
brew tap dev-null-sh/devnull https://github.com/dev-null-sh/mac-os-app
brew install --cask dev-null-sh/devnull/devnull
```

The cask always installs the latest release, and the app updates itself from then on.
